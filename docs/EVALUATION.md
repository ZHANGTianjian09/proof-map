# Mathematical paper map evaluation

## Ground truth and candidate separation

Choose papers with documented permission for the intended evaluation/distribution. Freeze the paper version, source/PDF hashes, appendices and supplements. Keep unpublished material local. Before inspecting candidate graphs, have mathematical reviewers inventory every formal object, including unnumbered objects, definitions, assumptions, examples and appendices. Record original labels, complete statements, source locators and scope judgments without inventing missing content.

Independently annotate relationships with endpoints, canonical relation, source evidence, explicit/inferred origin and reviewer rationale. Store source-backed uncertainty separately. A second reviewer should adjudicate disagreements; preserve both initial annotations and the adjudicated reference. Human ground truth is a reviewed reference with limitations, not independent proof verification.

Freeze the candidate graph and extraction tool/version/settings separately from the reference. Match nodes using source identity, original label and statement, not only generated IDs. Log ambiguous matches and duplicates. Never derive the reference inventory from the final candidate or silently repair the candidate before scoring. The V0 viewer supplies no extraction engine.

## Metrics

| Metric                  | Measurement                                                                                                                                                                                                                                                                                                                                                            |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Node coverage           | Correctly represented reference objects / all reference objects. Count each formal object once. Report missing, duplicated, merged and statement-corrupted objects separately, with breakdowns by type, section and appendix.                                                                                                                                          |
| Edge precision          | Correct candidate relationships / all candidate relationships. Correctness requires matched endpoints, relation semantics, orientation and appropriate evidence/origin. Unsupported or extra relations count as false positives; duplicates cannot inflate true positives.                                                                                             |
| Edge recall             | Recovered reference relationships / all reference relationships. Missing nodes also prevent recovery of their incident relationships. Report per relation and explicit/inferred origin.                                                                                                                                                                                |
| Provenance coverage     | Nodes with adequate source locators / all candidate nodes; separately, edges with adequate source support / all candidate edges. Review locator correctness and excerpt fidelity, not just field presence. Also report evidence coverage for explicit edges and supporting rationale for inferred edges separately.                                                    |
| Graph integrity         | Compare canonical input with export after import, indexing, layout, search, selection and filtering. Require exact semantic JSON equality including array order and raw strings. For scope edits allow only the explicitly requested scope-key change. Count losses, additions, reversals, metadata changes and status changes; any unexpected change fails integrity. |
| Visualization usability | With consent, ask researchers to find a main theorem, identify its prerequisites, inspect evidence, find an isolated appendix object and distinguish an inferred relation. Record task success, time, navigation errors, relation misinterpretations and readability feedback.                                                                                         |

For edge matching, retain `uses` prerequisite → dependent orientation and `generalizes` general → special. Match `equivalent_to` as an unordered endpoint pair while auditing that the viewer/export preserves the supplied orientation and one canonical record. Cycles, self loops, parallel records and disconnected components are legitimate. Distinguish meaningful parallel evidence records from duplicate extraction output during adjudication. Other relationship types are not automatically proof dependencies.

An empty denominator is reported as N/A with raw counts, not as perfect performance. Predefine inclusion/exclusion rules and matching policy. Report unresolved annotations and sensitivity to adjudication. In corpus summaries give per-paper results and both macro and pooled counts so large papers do not silently dominate. If uncertainty intervals are calculated, document the sampling unit and method.

## Reproducible report

Record paper/version/hashes, permissions, reference and candidate hashes, annotation protocol, reviewers/adjudication, tool version, test commit, environment and all metric numerators/denominators. Include representative source-backed errors and unresolved cases. Keep automatically extracted candidates separate from manually reviewed annotations and supplied verification labels.

For performance, measure file read/validation, worker layout, first interactive rendering, search and PDF export separately. Record graph size/connectivity, browser, machine, warm/cold runs, repeats and failures. Publish measured distributions only after running the protocol. The synthetic QA fixtures demonstrate software properties; they have no extraction quality scores and do not establish real-paper completeness or mathematical truth.
